# Provider identification marks

These small SVG marks identify setup instructions for Claude, ChatGPT (OpenAI),
Gemini, Grok and the Model Context Protocol. They do not imply endorsement,
partnership or verified provider-account interoperability.

Source: [Lobe Icons](https://github.com/lobehub/lobe-icons), pinned revision
`79b551cf26aab9ea4ac701fb807160950a5b860f`, directory
`packages/static-svg/icons/`. The unmodified SVG sources are:

| Local file | Upstream file |
| --- | --- |
| `claude.svg` | `claude-color.svg` |
| `chatgpt.svg` | `openai.svg` |
| `gemini.svg` | `gemini-color.svg` |

They contain no scripts, event handlers, external references or embedded images.
No icon package, third-party image request or runtime dependency is needed.
